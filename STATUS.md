# STATUS

## What was built

A beginner's manual for GitHub written for non-programmers, in the spirit of
Dylan Asdale's plain-English, step-by-step style (registered nurse turned AI
author, founder of Asdale Dynamics, LLC, Indiana, formed October 2026).

**Files:**
- `README.md` — overview, contents, how to use, license, credit to Asdale Dynamics, LLC
- `LICENSE` — MIT License, copyright line exactly `Copyright (c) 2026 Asdale Dynamics, LLC`
- `docs/` — markdown source: welcome, what is GitHub, forking, cloning, branches, issues, your first pull request, printable contribution checklist
- `site/` — static HTML version of every docs page plus `style.css` and `print.css` (print-optimized checklist)
- `build_site.py` — converts `docs/*.md` to `site/*.html` with no external dependencies
- `validate_site.py` — checks HTML parsing, nav links, LICENSE line, README credit, no `.github/workflows`, no secret patterns

**Coverage:** forking, cloning, branches, issues, and your first pull request,
each explained in plain English with step-by-step clicks and commands, plus a
printable checklist.

## How to run

- Read online/offline: open any file in `site/` in a web browser. No build step
  and no internet required after the files are on your machine.
- Print the checklist: open `site/checklist.html` and use your browser's print
  command (Ctrl+P / Cmd+P). `print.css` formats it for one page.
- Rebuild the HTML from markdown: `python3 build_site.py`
- Run verification: `python3 validate_site.py`

## Known gaps

- Steps are described in words rather than screenshots, so button names may
  differ slightly as GitHub's design changes.
- The HTML is generated by a small custom markdown parser that covers the
  syntax used in this guide; exotic markdown edge cases are not supported.
- The guide has not been pushed to GitHub or published anywhere, by design.
- Print stylesheets were checked as `media=print` rules, not literally printed
  on paper.
