# Your First Pull Request: A Beginner's Guide to GitHub

A plain-English, step-by-step manual for forking, cloning, branches, issues,
and your first pull request — written for non-programmers.

---

## Who this is for

You do not need to be a programmer to use GitHub. This guide was written for
anyone who wants to contribute to a project, fix a typo, suggest an idea, or
just see how open-source collaboration works.

It was created by **Dylan Asdale**, a registered nurse turned AI author and
founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026). Dylan
writes *The Massive AI Manual* and runs the hub site dylanasdale.github.io,
explaining AI "like a friend would": plain English, step by step, never
condescending.

Asdale Dynamics, LLC focuses on beginner-friendly AI education, books and
guides, practical tools, small-business and author tools, accessible
life-admin helpers, healthcare-worker AI aids (education only, never medical
advice), and fun extras like gaming and chess tools.

This guide is part of that mission: open, friendly, and free to share.

## How to use this guide

Each step is written like a recipe: do this, then do that. Screenshots and
exact buttons to click are described in words so you can follow along no
matter what device you are on.

There is also a static HTML version of this guide in the `site/` folder —
open any `.html` file in your web browser, no internet required after you
download it.
