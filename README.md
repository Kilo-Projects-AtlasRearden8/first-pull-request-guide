# Your First Pull Request: A Beginner's Guide to GitHub

A plain-English, step-by-step manual for forking, cloning, branches, issues,
and your first pull request — written for non-programmers, by a friend.

---

## Who this is for

You do not need to be a programmer to use GitHub. If you can click buttons and
type sentences, you can contribute to a project, fix a typo, suggest an idea,
or just see how open-source collaboration works.

This guide was written for anyone who has ever looked at a GitHub page and
thought, "I'd like to help, but I don't know where to start." That is exactly
where to start: right here, one step at a time.

## How to use this guide

Each step is written like a recipe: do this, then do that. Open this guide in
one window and GitHub in another, then work through one step at a time. Look
at your screen after each step to confirm it happened before moving on.

Button names and menus may look slightly different on your screen, because
GitHub updates its design now and then. The ideas stay the same — look for
words that mean the same thing.

There is also a static HTML version of this guide in the `site/` folder. Open
any `.html` file in your web browser. No internet required after you download
it, and nothing to install.

---

## You cannot break anything

GitHub is built for experimentation. Forking, cloning, and branching all work
on copies, so the original project stays safe while you learn. If something
does not look right, you can always start over on a fresh branch.
