# Contribution Checklist

Print this page and keep it by your desk. Check off each box as you go.

---

## Before you start

- [ ] I have a free GitHub account
- [ ] I found a public project I want to contribute to
- [ ] I have about 20 minutes

---

## 1. Forking

- [ ] I opened the project's page on GitHub
- [ ] I clicked the **Fork** button
- [ ] I chose my own account as the destination
- [ ] My fork appears at `github.com/my-username/project-name`

---

## 2. Cloning

- [ ] I copied the HTTPS address of my fork
- [ ] I opened a terminal
- [ ] I ran `git clone https://github.com/my-username/project-name.git`
- [ ] I ran `cd project-name`

---

## 3. Branches

- [ ] I ran `git checkout main`
- [ ] I ran `git pull origin main`
- [ ] I created a new branch: `git checkout -b branch-name`
- [ ] I confirmed with `git branch` that I am on the new branch
- [ ] I made my changes and saved the files
- [ ] I ran `git add .`
- [ ] I committed: `git commit -m "short description"`
- [ ] I pushed: `git push origin branch-name`

---

## 4. Issues (optional)

- [ ] I opened the **Issues** tab on the project page
- [ ] I clicked **New issue**
- [ ] I wrote a clear title
- [ ] I described what I found and where
- [ ] I clicked **Submit new issue**

---

## 5. Your first pull request

- [ ] I went to my fork on GitHub
- [ ] I clicked **Compare & pull request** (or **Contribute > Open pull request**)
- [ ] The base repository is the original project and the base branch is `main`
- [ ] The compare repository is my fork and the compare branch is my branch
- [ ] I wrote a clear title
- [ ] I wrote a short description of what and why
- [ ] I clicked **Create pull request**

---

## After your pull request

- [ ] I answered any questions from the project owner
- [ ] I pushed more commits if changes were requested
- [ ] The pull request was merged, or I accepted the decision not to merge
